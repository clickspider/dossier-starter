# 05-Cases

Fights and long admin tasks: a claim, a dispute, a warranty, a court case. One folder per case, each with a CASE.md.

Every topic that is more than a one-off question gets its own folder here, with:
1. `README.md`: what it is, why it matters, the key facts.
2. `NOW.md`: where it stands today, open loops, next date. Keep it short.
