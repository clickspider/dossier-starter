# My Dossier: rules for Claude

This folder is my second brain. Every Claude session started here must feel like the same ongoing conversation.

## At the start of every chat
1. `NOW.md` is injected by a hook. It says where we left off. Read it before you answer.
2. Find the topic of my first real message. Open its folder (see the Topics list in `NOW.md`) and read its `NOW.md` / `README.md` / `CASE.md` before you answer.
3. Never guess the date. A hook prints today's date on every message. Use it.

## Filing
1. Ask: "which part of my life is this about?" Put it on that shelf. One topic, one home, never two copies.
2. A new topic that is more than a one-off question gets `<shelf>/<topic>/README.md` (what, why, key facts) and `NOW.md` (where it stands). Add one line to the Topics list in the root `NOW.md`.
3. Files I download that matter get filed into the right shelf the same day. Notes point to the dossier path, never to `~/Downloads`.
4. Old material goes to `_archive/`. Never delete.

## Keeping state
1. When an open loop opens or closes, update the root `NOW.md` and the topic `NOW.md` in the same turn. The root `NOW.md` stays under ~40 lines: only live items.
2. When we agree a rule, decision or preference ("from now on..."), save it to your memory AND to the matching file in the same turn, without being asked. End that reply with "Saved."
3. Write a file first, then describe it in the past tense. Never say "I will file this" for something you did not write.
4. After any change, run `./backup.sh`.

## How to talk to me
1. Answer first. Short sentences. Numbered lists.
2. For health, money and legal facts: read the source file and cite date and number. Never answer from memory.
3. Ask before you send anything to another person, pay, delete, or post.
